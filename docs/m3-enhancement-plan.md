# M3 增强方案（吊牌排版专用）— 详细设计

> 状态：方案定案（2026-09-28，需求已与用户确认）
> 前置：M1 完成（双插件 X4 运行验证通过）；M2 推迟至 M3 完成后一并验收

---

## 1. 背景与目标

M1 已确认 corelvba + vbabox 双插件在 CorelDRAW X4 上可用（`Tools.尺寸标注`、`LinesForm` 均正常）。
M3 目标：为**吊牌（服装/鞋包挂牌）排版**补充三个行业专用增强，以**独立 VBA 模块**实现，
与 LYVBA/vbabox 并存、**不修改作者 GMS**。

工作流（不变）：设计师稿件（CDR 多页/多文件）→ 直接排版 → 印刷。**无可变数据环节**。

## 2. 需求确认记录（用户原话）

| 功能 | 用户确认 |
|---|---|

## 3. 功能设计

### 3.1 M3-A 不同规格混拼（矩形打包排版）

**场景**：一张印刷大版（纸张尺寸，如 70×100cm / 63×90cm），排入多个不同规格的吊牌（矩形），
自动计算每块位置，尽量紧凑。

**输入**：
- 当前文档选中多个对象，**每个对象 = 一个吊牌**（对象尺寸即吊牌成品尺寸；若吊牌由多对象组成，
  宏以"选中对象中最大的外边界"为一个吊牌单位 —— 见"对象分组"）
- 对话框参数：大版宽（mm）、大版高（mm）、对象间距（默认 = 出血×2 = 6mm，可调）

**对象分组规则**：
- 若用户选中 N 个互不相交的"组"（组内对象重叠/嵌套），每组合并为一个吊牌单元；
- 简化实现：以选中对象的**边界框**为单位 —— 相邻（间距 < 阈值）且重叠的对象并入同一吊牌，
  宏按边界框聚类分组；每组的整体边界 = 该吊牌尺寸。

**排布算法**（矩形装箱，VBA 实现）：
1. 按面积降序排序（大规格优先）
2. **Shelf（货架）算法**：在版面上逐行排布——当前行放不下则换行；行高 = 当前行最大高度；
3. 剩余空间再填小块（尾行尾列补插，可选做一版简化）
4. 输出：每块的 (x, y)（左下原点，毫米坐标）；任一块超出版面 → 提示"放不下，请减少数量或增大版面"
5. 用 `Shape.Move` 把对象移到计算位置（保持对象内部结构不变）

**注意**：间距 ≠ 出血 —— 吊牌拼版间距由刀线/工艺决定（默认 6mm，可调）；出血在 M3-B 处理。

### 3.2 M3-B 自动出血（3mm，两种模式）

**模式 1：背景图向外扩展**（适用于吊牌含整版底色/背景矩形）
- 选中背景矩形（或含背景的对象组）→ 中心不动，宽高各 +6mm（四边各外扩 3mm）
- 实现：读 `GetBoundingBox` → 改 `Shape.SizeWidth/SizeHeight` 或按新边界重定位
- 约束：仅扩展**填充类背景**（矩形/椭圆/曲线闭合轮廓）；文字/图形对象不扩展

**模式 2：描边加一圈**（适用于背景无整版矩形、需要轮廓出血）
- 选中吊牌对象 → 按其外边界生成**扩展矩形**（四角外扩 3mm）
- 扩展矩形填充 = 吊牌边缘采样色（取边界外圈最接近的像素/对象色，简化：取背景层对象填充色）
  —— **简化 v1**：取选中对象组的填充色（若背景为白色则白底），生成无轮廓色块置于底层
- 效果 = 印刷上"四周多一圈同色出血边"

**交互**：一个对话框两个模式单选 + 出血值（默认 3mm，可调）。

### 3.3 M3-C 角线组（套准十字 + 裁切角线）

**组成**：
- **套准十字**：四角各一个十字标记（水平 + 垂直短线交叉）
- **裁切角线**：四角 L 形角线（外延线）+ 四边中点短标记线

**参数（默认值，对话框可调）**：
- 外延（角线伸出对象边界）：默认 5mm
- 线长：默认 8mm
- 距边（角线起点离对象边界）：默认 0mm（从边界外延）
- 线宽：默认 0.1mm（细线，印刷套准线习惯）
- 颜色：默认黑色（可调 K100）

**实现**：
- 以选中对象边界（或页面边界）为基准 → 计算 8 个锚点（四角 + 四边中点）
- 角点：画 L 形两条线（外延+线长）；十字：交叉两条线（对称外延）
- 四边中点：垂直短标记线（朝外）
- 全部置于**最上层**、独立成组（便于整体删除：宏再提供一个"删除角线组"——按图层/组名标记）

**宏接口**：`TagCornerMarks` 生成；`TagRemoveCornerMarks` 删除（按标记组识别）。

## 4. 宏接口一览（独立 GMS：LanyaTagPack）

| 宏名 | 功能 |
|---|---|
| `TagMixPacking` | 不同规格混拼（对话框：大版宽/高/间距） |
| `TagAddBleed` | 自动出血 3mm（对话框：模式=扩展背景/描边加圈、出血值） |
| `TagCornerMarks` | 角线组（对话框：外延/线长/距边/线宽/颜色） |
| `TagRemoveCornerMarks` | 删除角线组 |

模块：`TagMain.bas`（入口+对话框）、`TagPacking.bas`（混拼算法）、`TagBleed.bas`（出血）、`TagMarks.bas`（角线）。
**全部 VBA6 兼容语法**（X4）：无 PtrSafe/LongPtr；Declare 仅用 X4 支持的内置 API 或不用。

## 5. 技术要点

- **目标运行时**：CorelDRAW X4（32 位，VBA6）。参考现有可用写法：`upstream/corelvba/module/`、
  `upstream/vbabox/`（Shape 操作、单位换算、Selection 枚举）。
- **单位**：文档单位 mm（`ActiveDocument.Unit` 或按文档设置读取）；对话框输入 mm。
- **API 参考**（X4 对象模型）：
  - 选中对象：`ActiveSelection` / `ActiveSelectionRange`
  - 边界：`Shape.GetBoundingBox(x1, y1, x2, y2)`
  - 移动：`Shape.Move dx, dy`（按文档单位）
  - 画线：`ActiveLayer.CreateLineSegment x1, y1, x2, y2`（或 CreateCurve）
  - 矩形：`ActiveLayer.CreateRectangle`
  - 轮廓：`Shape.Outline.SetProperties Width:=..., Color:=...`
  - 填充：`Shape.Fill.UniformColor`
  - 成组：`ActiveSelection.Group` / `ShapeRange.Group`
  - 标记组标识：`Shape.Name` 赋值（如 "LY_TAG_MARKS"）便于删除时识别
- **健壮性**：所有宏开头 `On Error GoTo` 保护 + 无选择/选择异常时提示退出，不产生副作用。

## 8. 风险与边界

- X4 VBA 无高级矩形打包库：混拼用 Shelf 贪心（非最优，但吊牌场景足够；先跑通再优化）
- 出血"描边加一圈"颜色采样为简化版（取背景填充色），复杂渐变背景需人工复核
- 角线删除按 `Shape.Name` 标记识别：用户手动改名/解除组后可能失效（文档中说明）
